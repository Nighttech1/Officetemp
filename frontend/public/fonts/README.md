# Fonts for IUL PDF

## Times New Roman (ИУЛ, C-127)
- `TimesNewRoman.ttf`, `TimesNewRoman-Bold.ttf` — копия системных `times.ttf` / `timesbd.ttf` для точного соответствия `templates/ИУЛ template.docx`.
- Лицензия Microsoft: только для локального/внутреннего использования на машине с лицензией Windows. Не распространять отдельно.

## DejaVu (legacy C-99)
- `DejaVuSans.ttf`, `DejaVuSans-Bold.ttf` — Bitstream Vera / free to embed (запасной кириллический набор).
