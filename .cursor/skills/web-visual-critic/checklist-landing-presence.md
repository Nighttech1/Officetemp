# Landing presence — дополнение к visual checklist

Использовать **вместе** с основным `checklist-visual.md` для публичного `/`.

## Presence (0.5 сек на 1440)

- [ ] Hero занимает почти весь первый viewport (не «островок» по центру)
- [ ] Headline читается как доминанта; бренд DocSaaS не теряется
- [ ] Signature (фигурки/видео/film) крупный, не thumbnail
- [ ] Есть атмосфера плоскости (не голый `#e8e8e6` без глубины)
- [ ] CTA группа видна без скролла
- [ ] Убрать nav → страница всё ещё «DocSaaS documents», не generic SaaS

## Анти-пустота

- [ ] Мёртвый фон ≤ ~30% первого экрана
- [ ] Нет ощущения «макет забыли доделать»
- [ ] Секции чередуют плоскости; не одна серая простыня вниз

## Client-ready

- [ ] Можно скинуть заказчику без извинений «это черновик»
- [ ] Mobile 390/412: denser stack, без огромных пустот между title и CTA
- [ ] Пройден `.cursor/skills/landing-client-ready/SKILL.md`

Провал любого Presence = отдельный `C-*` приоритета **P0/P1**.
