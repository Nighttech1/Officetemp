description: Глубокий аудит доступности (контраст, клавиатурная навигация, focus trap, skip-link, ARIA). Использовать для проверки accessibility в интерфейсах.

## Инструкции
1. Проверять контраст цветов по WCAG.
2. Тестировать клавиатурную навигацию (tab order, focus trap).
3. Добавлять skip-links на ключевых страницах.
4. Валидировать использование ARIA-атрибутов.
5. Документировать проблемы и предлагать решения.
