# Промт: второй цикл безопасности

Когда пользователь пишет «запускаем второй цикл безопасности» (или синоним из `SECOND_SECURITY_CYCLE.md`):

1. Прочитать `SECOND_SECURITY_CYCLE.md`, `.cursor/rules/security.mdc`, `.cursor/rules/hacker.mdc`.
2. Не смешивать с обычной фазой roadmap.
3. Выполнить chain: **Тренер** → Архитектор (scope) → Security → Hacker → Фиксер → Тестировщик → Деплоер → Клиент.
4. Каждое сообщение роли начинать с «СЕЙЧАС РАБОТАЕТ АГЕНТ …».
5. Цель по умолчанию localhost; иначе — URL из команды пользователя.
