# C-41 — Единая шапка и футер на всём сайте

**Priority:** P0  
**Status:** done  
**Wave:** W-16

## Проблема
На страницах `/app/*`, `/contact`, `/login` показывается другая (кабинетная) шапка и урезанный футер. Пользователь требует: шапка и футер **с лендинга** (`LandingNav` + `LandingFooter`) всегда на всех страницах сайта.

## Acceptance
- [ ] На `/`, `/app/documents/waybills`, `/contact`, `/login` видна одна и та же шапка DocSaaS (Документы ▾, Контакты, Личный кабинет)
- [ ] На этих же URL виден полный футер лендинга (DocSaaS, Войти, Регистрация, Контакт, Кабинет, ©)
- [ ] Дубликатов шапки/футера нет
- [ ] Лендинг визуально не сломан (nav поверх тёмного hero)
