### [C-11] Авторизация и личный кабинет компании
- **Зона / Экран:** `/login`, `/register`, `/app` (профиль)
- **Факт:** Нет UI — только API.
- **Ожидание:** Регистрация (орг + email + пароль), вход, экран «я / компания» из `/auth/me`; JWT в localStorage/cookie; выход; адаптив ≥390.
- **Приоритет:** P0
- **Зона:** Frontend
