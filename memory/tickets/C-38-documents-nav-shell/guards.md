# Guards C-38 / W-15 Documents

1. В шапке лендинга и `/app` есть пункт «Документы» (не «Шаблоны / Маппинг / Генерация»).
2. Выпадающий список ведёт на `/app/documents/info-sheet` и `/app/documents/waybills`.
3. `/app/documents/waybills` открывается без обязательного входа; слева проекты, справа пустой hint или мастер.
4. Создание проекта → «+ Документ» открывает WaybillWizard с шагами 1–5.
5. «Перегенерировать» создаёт документ с version+1; поиск фильтрует список; удаление убирает документ из сайдбара.
