### [C-207] ИУЛ: смена документа в дереве не должна «обновлять» весь мастер
- **Зона / Экран:** `/app/documents/info-sheet`
- **Факт:** При клике на другой ИУЛ в дереве основное окно визуально перезагружается (FadeIn / сброс / мигание), хотя нужно только подставить данные в поля и превью.
- **Ожидание:** Каркас мастера (табы шагов, кнопки, превью-оболочка) стабилен; меняются только значения полей и превью. Без fade/slide при смене docId.
- **Приоритет:** P0
- **Зона:** Frontend
