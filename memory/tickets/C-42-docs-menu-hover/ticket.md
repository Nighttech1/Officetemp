# C-42 — Dropdown «Документы» закрывается при наведении

**Priority:** P0  
**Status:** done  
**Wave:** W-17

## Проблема
Выпадающий список «Документы» пропадает, когда курсор едет с кнопки к пунктам — невозможно кликнуть «Накладные» / «Информационно-удостоверяющий лист».

## Причина
`mt-1` между кнопкой и панелью: в зазоре срабатывает `mouseleave` на родителе.

## Acceptance
- [ ] Можно навести на «Документы», спокойно провести курсор к пункту и кликнуть
- [ ] Меню не мигает при движении курсора
- [ ] Клик вне меню и Escape по-прежнему закрывают
