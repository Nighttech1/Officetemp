# C-820 — Превью: fit по ширине + zoom/pan

Priority: P0  
Wave: W-82

## Проблема

В окне предпросмотра накладная не вписывается в максимальную ширину экрана/панели.

## Ожидание

1. Загруженный шаблон всегда масштабируется так, чтобы ширина страницы Word ≤ ширины окна превью (без горизонтального обрезания).
2. Сбоку вертикальная панель кнопок: приблизить / отдалить / сброс fit / режим перемещения (pan).
3. Колёсико/drag в режиме pan перемещает документ внутри окна.

## Поверхности

`WaybillLivePreview.tsx`, `globals.css` (`.docx-waybill-preview`), опционально `ResizablePreviewShell.tsx`.
