# Architect spec — C-94 W-40

## Проблема
`doc_name` заполнялся из штампа (`sheet_name` / «Общие данные»). Это имя **листа**, не документа.

## Правило (гибкое)
1. Искать **титульный лист** среди первых страниц (маркеры: ЗАСТРОЙЩИК/ЗАКАЗЧИК/ОБЪЕКТ, «Рабочая/Проектная документация», шифр).
2. Найти строку **шифра** (designation).
3. Взять 1..N строк **сразу над шифром** до стоп-маркеров (тип документации, ОБЪЕКТ, год, SIGN).
4. Склеить в одно наименование; не брать «Общие данные» / роли / даты / чистый шифр.
5. Fallback: хвост имени файла (если это не шифр). Штамп → только object_name / подписи, **не** doc_name.
