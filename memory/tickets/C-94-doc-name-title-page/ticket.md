### [C-94] Наименование документа — только с титульного листа

- **Зона / Экран:** ИУЛ мастер → поле «Наименование документа»
- **Факт:** Алгоритм подставлял «Общие данные» (название листа из штампа), а не реальное наименование с титула.
- **Ожидание:** Наименование берётся с титульного листа (блок над шифром). Примеры:
  - `Вертикальные несущие конструкции на отм. -4.100, …, -3.400. Секция 2`
  - многострочный блок `Раздел … / Часть … / … / Корректировка`
  - «Общие данные» **никогда** не является наименованием документа
- **Приоритет:** P0
- **Скрин-улика:** user red boxes on title pages
- **Зона:** Backend
