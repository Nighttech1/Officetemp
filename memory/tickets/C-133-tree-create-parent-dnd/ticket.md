### [C-133] Дерево: папка/файл под выделенной; DnD без onLibraryChange; без prompt

- **Факт:** Новая папка/файл создаётся внутри только что созданной (после create срабатывает select на новую). DnD показывает `onLibraryChange is not defined`. Prompt при создании папки.
- **Ожидание:** Создавать внутри **текущей выделенной** папки; после создания папки выделение остаётся на родителе. Имя сразу «папка», без окна. DnD без ReferenceError.
- **Приоритет:** P0
- **Статус:** open
- **Волна:** W-55
