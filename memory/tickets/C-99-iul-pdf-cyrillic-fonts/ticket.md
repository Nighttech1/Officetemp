### [C-99] PDF ИУЛ — кириллица / шрифты «летают»

- **Зона:** ИУЛ → скачивание PDF
- **Факт:** При скачивании PDF ИУЛ русские буквы отображаются криво / пропадают (шрифты «летят»).
- **Причина (гипотеза):** `jspdf` рисует текст стандартным Helvetica без кириллицы.
- **Ожидание:** В скачанном PDF все русские заголовки и поля читаются нормально; шрифт встроен в файл.
- **Приоритет:** P0
- **Зона:** Frontend (`iul-pdf.ts`)
- **Статус:** done (DejaVuSans embedded; sample-iul-cyrillic.pdf + after-preview.png)
