# Guards C-99 — кириллица в PDF ИУЛ

## Авто
```text
cd frontend
npx tsx lib/iul-pdf.selftest.ts
```
Ожидание:
- файл `sample-iul-cyrillic.pdf` создан
- в PDF встроен `DejaVuSans` (Type0 / Identity-H)
- pymupdf `get_text()` содержит «Информационно-удостоверительный» и русские поля

## Ручная
1. Открыть мастер ИУЛ → сформировать PDF с русским объектом/наименованием.
2. Открыть скачанный файл: заголовок и таблицы читаются по-русски, не кракозябры.
