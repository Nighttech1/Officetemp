### [C-74] Шапка шагов SlideTabs срабатывает через раз
- **Зона / Экран:** ИУЛ · верхние табы шагов (Файл / Документ / Подписи / PDF)
- **Факт:** Клик по шагу срабатывает нестабильно («через раз»).
- **Ожидание:** Каждый клик/Enter/Space сразу переключает шаг; индикатор плавно едет к выбранному; оверлей не перехватывает клики (`pointer-events-none`).
- **Приоритет:** P0
- **Статус:** open
- **Зона:** Frontend
