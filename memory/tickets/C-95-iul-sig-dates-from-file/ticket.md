### [C-95] Даты всех подписантов = дата изменения ИУЛ

- **Зона:** ИУЛ мастер / превью / PDF
- **Факт:** У подписантов даты со штампа (разные).
- **Ожидание:** Одна дата у всех = дата изменения файла ИУЛ (`fileModifiedAt`, только ДД-ММ-ГГГГ). При смене даты изменения — обновить все подписи.
- **Приоритет:** P0
- **Зона:** Frontend
