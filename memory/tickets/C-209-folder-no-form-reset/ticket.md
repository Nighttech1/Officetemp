### [C-209] Не сбрасывать форму при смене папки
- **Зона:** дерево → мастер ИУЛ (и согласованно Накладные)
- **Факт:** file→file поля статичны (ок); folder→folder обновляет/сбрасывает форму
- **Ожидание:** смена папки в том же проекте не перезагружает мастер, пока не сменился документ
- **Приоритет:** P1 · Frontend
