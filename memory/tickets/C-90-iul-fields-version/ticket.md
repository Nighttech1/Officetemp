### [C-90] ИУЛ: обозначение с Изм., наименование документа, версия «-» не «0»

- **Зона / Экран:** ИУЛ · шаг 2 + превью + PDF
- **Факт:** Версия иногда «0»; шифр без приписок Изм.; в превью колонка «Наименование» без слова «документа».
- **Ожидание:**
  1. Версия пустая или «0» → в бланке **-**.
  2. Обозначение документа = полный шифр со всеми приписками (Изм. N и т.п.).
  3. Наименование документа = название раздела буквами (не шифр).
  4. Подписи колонок: «Обозначение документа» / «Наименование документа».
- **Приоритет:** P0
- **Зона:** Frontend + Backend stamp/filename hints
