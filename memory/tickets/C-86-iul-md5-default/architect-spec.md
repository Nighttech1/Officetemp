# Architect spec — W-37 (C-86 / C-87 / C-88)

## Цель

Улучшить UX пакетного ИУЛ: настроить проект до загрузки PDF, MD5 по умолчанию с корректной длиной хэша, даты и версия в бланке по правилам заказчика.

## Контракт

### C-86 — MD5 default
- `emptyIulWizard().hashAlgo` → `"MD5"`.
- В `Project.iulSignSettings` добавить `defaultHashAlgo?: InfoSheetHashAlgo` (default при отсутствии = `MD5`).
- `seedIulFromPdf` и `applyFile` в мастере: алгоритм =
  `opts.hashAlgo ?? project.iulSignSettings?.defaultHashAlgo ?? "MD5"`.
- Batch (`handleBatchCreate`) передаёт algo из настроек проекта.
- Hint длины хэша через `expectedHashHexLen(algo)`.

### C-87 — Настройки + всегда открытый мастер
- Кнопка **«Настройки»** (не «Настройки ролей») в шапке мастера рядом с «Сформировать PDF/ИУЛы».
- Панель настроек: фиксированные характеры + overflow + **базовый алгоритм хэширования**.
- Убрать дублирующую кнопку с шага 3 (или оставить только шапочную).
- Страница `info-sheet`: если нет выбранного документа и не библиотека подписей — **автосоздать/выбрать черновик ИУЛ** проекта, чтобы мастер всегда на экране.

### C-88 — Даты и версия
- `formatFileModifiedAt` → дата в **ДД-ММ-ГГГГ** (время HH:MM:SS можно оставить после даты).
- Хелпер `formatIulDisplayDate(raw)` → ДД-ММ-ГГГГ для signedAt / ISO / уже ДД-ММ-ГГГГ.
- Превью + `buildIulPdfBlob`: даты через хелпер; `docVersion` пустой → `"-"`.
- Seed: не подставлять `"0"` если версии нет — оставить пустым (в бланке будет `-`).
- Backend `_parse_date`: можно оставить ISO; фронт форматирует при показе. Опционально сразу отдавать ДД-ММ-ГГГГ — предпочтительно единообразие на фронте.

## Вне scope
- Backend schema / Alembic (настройки в localStorage + workspace JSON).
- Prod/VPS.

## Acceptance (язык Клиента)
1. Открыл ИУЛ → сразу виден мастер и «Настройки» рядом с «Сформировать».
2. В настройках выставил MD5 (или уже MD5) → пакетная загрузка PDF → хэш 32 символа.
3. В превью/PDF даты ДД-ММ-ГГГГ; пустая версия = `-`.
