### [C-86] Пакетная загрузка ИУЛ: алгоритм хэша MD5 по умолчанию

- **Зона / Экран:** ИУЛ · пакетная загрузка PDF + мастер шаг 1
- **Факт:** При пакетной загрузке хэш считается не MD5 (сейчас по умолчанию SHA-256), длина строки не совпадает с MD5 (ожидается 32 символа).
- **Ожидание:** Стартовый алгоритм хэширования проекта — **MD5**. Пакетная и одиночная загрузка берут его из настроек проекта; длина хэша = 32 hex-символа при MD5.
- **Приоритет:** P0
- **Скрин-улика:** после фикса — длина хэша 32 при пакетной загрузке
- **Зона:** Frontend
