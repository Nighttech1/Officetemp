### [C-202] Вёрстка Накладные/ИУЛ + шапка над деревом
- **Зона / Экран:** `/app/documents/waybills`, `/app/documents/info-sheet`
- **Факт:** при изменении ширины экрана ломаются вкладки шагов (ШАБЛОН и др.) и сетка; сверху дерева лишний блок «DocSaaS · Накладные / Проект → …» + Home

- **Приоритет:** P0
- **Скрин-улика:** скрин пользователя (ломаная вкладка ШАБЛОН) + крест на шапке дерева
- **Зона:** Frontend
