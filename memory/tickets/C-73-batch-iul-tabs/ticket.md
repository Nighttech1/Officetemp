### [C-73] Пакетное создание ИУЛ из нескольких PDF
- **Зона / Экран:** ИУЛ · мастер + сайдбар
- **Факт:** Один PDF → один ИУЛ; нет пакетного режима и вкладок по файлам.
- **Ожидание:**
  1. Кнопка «создать несколько документов» → окно приёма нескольких PDF.
  2. На каждый PDF создаётся ИУЛ в **текущей** папке (или корне проекта).
  3. В пакетном режиме на **каждом** шаге мастера слева вертикальные Tabs (как у подписантов): вкладка = имя PDF; содержимое шага — данные этого документа.
  4. Кнопка генерации/скачивания: **«Скачать ИУЛы»** (мн.ч.); скачиваются все ИУЛы пакета.
- **Приоритет:** P0
- **Статус:** open
- **Зона:** Frontend (+ Doc Engine клиентский PDF)
