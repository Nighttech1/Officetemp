# C-57 — Правило Клиента: всегда скачать готовый документ и сравнить с оригиналом

**Priority:** P0 · **Wave:** W-24 · **Status:** done

### Ожидание
В `.cursor/rules/client.mdc` и skill `client-review` жёстко зафиксировано:
- приёмка мастера документов **не завершена** без реального скачивания готового DOCX/PDF;
- скачанный файл **сравнивается** с первоначальным шаблоном/эталоном пользователя;
- без этого запрещено писать «согласовано».

### Зона
Rules / client-review (не код продукта).
