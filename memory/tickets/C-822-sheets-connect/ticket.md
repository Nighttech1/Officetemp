# C-822 — Google Sheets: UX connect + реальное подключение

Priority: P0  
Wave: W-82

## Проблемы

1. Большая задержка, пока «Подключить» становится активной / отзывчивой.
2. При уходе фокуса из поля ссылки срабатывает авто-подключение — убрать; только кнопка.
3. После нажатия «Подключить» нужен текст «подключаемся…» и анимированный зелёный «огонёк» по единому контуру поля+кнопки.
4. Само подключение по ссылке не происходит, хотя у таблицы есть права доступа.

## Ожидание

- Paste/blur **не** вызывают connect.
- Connect только по кнопке; на время запроса: label «подключаемся…» + running border.
- Успех: строки/листы в мастере; ошибка — понятный текст без ложного «ок».
