### [C-107] Поле «Дата подписания» пустое при заполненном превью/PDF
- **Зона / Экран:** ИУЛ → шаг 3 «Подписи» → поле type=date
- **Факт:** В превью и PDF дата есть (дд.мм.гггг), в input type=date — пусто.
- **Ожидание:** В поле даты подписания видна та же дата. HTML date требует YYYY-MM-DD; хранение/конвертация согласованы с formatIulDisplayDate.
- **Приоритет:** P0
- **Зона:** Frontend
