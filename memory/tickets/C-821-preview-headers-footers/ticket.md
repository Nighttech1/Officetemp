# C-821 — Превью: колонтитулы Word

Priority: P0  
Wave: W-82

## Проблема

В окне предпросмотра не отображается содержимое колонтитулов (header/footer) документов Word.

## Ожидание

Верхний и нижний колонтитулы из `.docx` видны в live-preview так же, как тело документа (или с явной визуальной зоной header/footer).

## Поверхности

`WaybillLivePreview.tsx` (опции `docx-preview`), CSS превью, при необходимости Doc Engine (если колонтитулы теряются при generate).
