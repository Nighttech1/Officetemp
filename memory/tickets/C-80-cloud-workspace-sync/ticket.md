### [C-80] Облачный ЛК: проекты ИУЛ/накладные в Postgres (источник правды)
- **Зона / Экран:** Личный кабинет → дерево проектов слева; любой браузер после входа
- **Факт:** Сейчас проекты, папки и черновики мастеров лежат только в localStorage браузера. На другом ПК / другом браузере данных нет.
- **Ожидание:** После входа в ЛК пользователь видит **свои** проекты с любого устройства. Сервер (PostgreSQL на VPS в РФ) — источник правды. localStorage продолжает **дублировать** снимок «на всякий случай» (офлайн/быстрый старт), но не является единственным хранилищем.
- **Приоритет:** P0
- **Скрин-улика:** после реализации — два браузера, один аккаунт, одинаковое дерево
- **Зона:** Backend | Frontend | Personal-Data DB | Deploy
- **Не хранить на сервере:** исходные PDF чертежей (только метаданные мастера ИУЛ, как сейчас локально)

### [C-81] Библиотека подписей + blob-файлы накладных в облаке (tenant-изоляция)
- **Зона / Экран:** Библиотека подписей; шаблоны Word/Excel накладных
- **Факт:** Подписи (картинки) и шаблоны накладных сейчас в localStorage / IndexedDB браузера.
- **Ожидание:** Картинки подписей и шаблоны данных накладных привязаны к организации пользователя, доступны после логина с любого браузера. Исходные PDF для ИУЛ **не** загружаются в облако. Доступ строго по `organization_id` (запрет чужих данных = P0).
- **Приоритет:** P0
- **Зона:** Backend | Frontend | Deploy

### [C-82] 152-ФЗ: согласие, политика, регистрация без подтверждения почты (MVP)
- **Зона / Экран:** Регистрация / вход / политика конфиденциальности
- **Факт:** JWT-регистрация уже есть (email в схеме `pii`, пароль только как hash). Нет явного чекбокса согласия и пользовательского текста политики под облачный синк.
- **Ожидание:** Можно регистрироваться **без** подтверждения почты (закон 152-ФЗ этого не требует). Обязательны: согласие на обработку ПДн, политика, хранение ПДн на сервере в РФ, минимизация полей, audit, право на удаление аккаунта. Пароль никогда не хранить открытым текстом.
- **Приоритет:** P0
- **Зона:** Backend | Frontend | Personal-Data DB | Documentation
