### [C-130] Дерево: перенос файлов drag-and-drop (мультивыбор)

- **Зона / Экран:** сайдбар `ProjectSidebar` + `TreeView` (ИУЛ / Накладные)
- **Факт:** Файлы нельзя перетащить зажатием из папки в папку; мультивыбор есть, но DnD нет.
- **Ожидание:** Зажать файл → перетащить на папку → файл оказывается в ней. Если выделено несколько файлов — переносятся все. Папки на папки (опционально через существующий `moveFolder`) не ломать multi-select и rename.
- **Приоритет:** P0
- **Скрин-улика:** замечание пользователя п.1
- **Зона:** Frontend
- **Статус:** open
- **Волна:** W-54
