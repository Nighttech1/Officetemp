### [C-100] PDF ИУЛ: подписи, центр, без «Продолжение УЛ», даты с точкой

- **Зона:** ИУЛ → PDF (+ форматы дат в бланке/превью)
- **1.** Картинки подписей растянуты — должны быть как в библиотеке (пропорции без растяжения).
- **2.** Содержимое всех ячеек — по центру.
- **3.** Убрать фразу «Продолжение УЛ к документу …».
- **4.** Даты: `дд.мм.гггг` (точка), не через `-`.
- **Приоритет:** P0
- **Статус:** done (подписи aspect, центр, без «Продолжение УЛ», даты дд.мм.гггг)
