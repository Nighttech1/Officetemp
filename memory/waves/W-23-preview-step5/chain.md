### C-54 — ответы 2.1 (зафиксировать в UI)

**Таблица в шаблоне Word:** алгоритм не «угадывает» визуальную таблицу. Он ищет в файле команды docxtpl:
- строка `{%tr for row in ИМЯ %}` = начало повторяемой строки таблицы;
- строка с `{{ row.поле }}` = образец строки;
- `{%tr endfor %}` = конец.
Шапка Word — обычные ячейки **выше** цикла (без этих команд). Их алгоритм не меняет.

**Шапка таблицы данных (Excel/Google):** при чтении файла берётся строка, которая больше всего похожа на заголовки колонок (короткие уникальные подписи в первых ~20 строках), а не длинный титул листа. Имена из этой строки = колонки для стыковки на шаге 3.
