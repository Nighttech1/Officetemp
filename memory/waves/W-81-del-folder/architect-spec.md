# W-81 — C-225 Удалить папку на Накладных

## Симптом
Кнопка «Удалить папку» сверху пропадает при переходе в раздел Накладные.

## Гипотезы
| ID | Причина |
|----|---------|
| H1 | Кнопка есть в DOM, но toolbar шире сайдбара → overflow:hidden обрезает (хуже при длинной подписи «Добавить накладную») |
| H2 | После смены раздела selectedFolderId сбрасывается → disabled + opacity 0.4 ≈ «пропала» |
| H3 | Разный состав treeActions (без batch) ломает layout MultiButton |

## План
1. Единый toolbar: те же 4 действия на обоих разделах
2. Не обрезать: overflow-x-auto / компактнее иконки; не терять folder target
3. enabled, если выбрана папка ИЛИ документ лежит в папке
4. Проверка ИУЛ ↔ Накладные
