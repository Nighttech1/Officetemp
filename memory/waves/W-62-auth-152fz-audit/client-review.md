# W-62 — Клиент: аудит входа / 152-ФЗ / восстановление пароля

## Вердикт
**ПРИНЯТО С ЗАМЕЧАНИЯМИ**

- Хранение данных входа — **в целом правильно** (хеш пароля, ПДн отдельно).
- 152-ФЗ в коде — **частично закрыто** (согласие, изоляция ПДн, export/erase); это **не** полная юридическая сертификация.
- Механизм «забыли пароль» — **не настроен** (ни API, ни UI).

Слово «согласовано» по комплаенсу в целом — **не даём** (нет reset + политика-черновик + нет шифрования колонок/RLS).

---

## 1. Как хранятся данные для входа

| Данное | Где | Как |
|--------|-----|-----|
| Пароль | таблица `users.password_hash` (public) | **bcrypt** через passlib (`hash_password` / `verify_password`) — **не** открытый текст |
| Email, ФИО, телефон | схема `pii.user_profiles` | только через `PiiService` + audit |
| Согласие | `pii.user_profiles.consent_at` | без `consent=true` регистрация → 400 |
| Сессия после входа | JWT в браузере (`localStorage`) | HS256, срок из `JWT_EXPIRE_MINUTES` |

Идентификатор входа: email (или временный логин admin1) → поиск профиля в ПДн → проверка `password_hash`.

---

## 2. 152-ФЗ (по факту в продукте)

### Уже есть
- Согласие на обработку при регистрации (чекбокс + API)
- Разделение: auth без email в `users`, ПДн в схеме `pii`
- Журнал доступа `access_audit`
- Права субъекта: `GET /profile/me/export`, `POST /profile/me/erase`
- Политика TTL ПДн (настройка + Celery hook)
- Черновик политики: `/privacy` (нужна правка юристом перед боем)
- Заявлено хранение в РФ (на VPS) в тексте политики

### Пробелы / риски
- Нет **подтверждения email**
- Нет **column encryption / RLS** на ПДн (6.2.6–7 желательно)
- Политика — черновик, без реквизитов оператора
- Временные demo-логины на экране входа (для prod убрать)
- Export/erase в UI «Связаться» в тексте политики устарели vs реальные API

---

## 3. «Забыли пароль» / восстановление

| Слой | Статус |
|------|--------|
| Backend API (`/auth/forgot`, `/auth/reset`) | **нет** |
| Токены сброса / TTL / одноразовость | **нет** |
| Письмо на email (SMTP) | **нет** для reset (SMTP есть только для контакт-форм) |
| UI «Забыли пароль?» на `/login` | **нет** |
| Упоминание в `/privacy` | «позже можно включить» |

**Вывод:** восстановить пароль сейчас нельзя — только знать пароль или регистрироваться заново / правка админом в БД.
