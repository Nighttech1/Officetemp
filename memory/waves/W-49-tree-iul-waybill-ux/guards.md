## C-113 плавный expand
- Причина дерганья: `animateExpand={false}` + смена `icon` в `treeData` на каждый expand (полный ребилд).
- Исправлено: `animateExpand` + иконки внутри TreeView; duration ~0.28s, ease `[0.32,0.72,0,1]`.
- Playwright: expand → дети видны; collapse → `data-expanded=false`, count узлов = 3.
