# Второй цикл безопасности (Security + Hacker)

Этот цикл **не** входит в обычные фазы 1–5 разработки. Его запускает только пользователь специальной фразой.

## Спецкоманды (любая из них)

- `запускаем второй цикл безопасности`
- `запускаем цикл Security+Hacker`
- `запускаем пентест-цикл`
- `второй цикл: безопасность`

Можно добавить URL стенда: `запускаем второй цикл безопасности на http://localhost:8000`.  
По умолчанию цель — **localhost**. Prod/VPS — только если в той же фразе явно указано и согласовано.

## Chain второго цикла

```
Тренер → Архитектор (scope) → Security → Hacker → Фиксер → Тестировщик (регресс) → Деплоер (localhost) → Клиент
```

Тренер перед scope проверяет: skills security/hacker, MCP/плагины ZAP/sqlmap-карточки, data-safety, отсутствие прод-скана без явного URL.

Параллельно Security обязан проверить:
- Personal-Data DB (152-ФЗ)
- Payment Processor (webhooks, чеки, IDOR на счетах)

Лимит Оркестратора: максимум 3 тикета за волну. Hacker/Security заводят `S-*` / `C-*` по договорённости.

## Что не делать

- Не звать Hacker/Security в фазах 1–5 без спецкоманды
- Не сканировать чужие/боевые системы без явного URL в команде
- Не удалять ПДн и БД
